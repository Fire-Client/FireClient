## ✨ Features

- 🎮 **Minecraft launcher** that installs and runs Minecraft versions for you
- 🔌 **Offline Mode** play without signing in, with local offline skins
- 🔐 **Online Mode** play with Microsoft / Xbox / Minecraft sign-in
- 🧩 **Mod loader support:** Fabric, Forge and NeoForge
- 📦 **Profiles** for different versions, mods, resource packs and worlds
- 🛒 **Mod, resource pack and shader downloads** via Modrinth
- 💬 **Optional community features:** friends, messages, server listings
- 🟣 **Discord Rich Presence** (optional)
- 📸 Screenshots, logs and a copy-diagnostics action for easy support
- ⚡ Lightweight Windows installer

## 🔌 Offline Mode and 🔐 Online Mode

| | Offline Mode | Online Mode |
|---|---|---|
| Microsoft account needed | No | Yes |
| Singleplayer | ✅ | ✅ |
| Online-mode servers | ❌ | ✅ |
| Offline-mode / cracked-friendly servers | ✅ | ✅ |
| Custom offline skins | ✅ | Uses your account skin |
| Account data stored | None | Token stored locally, protected with Windows DPAPI |

> Online-mode servers verify your account with Mojang/Microsoft. To join them you must sign in with a legitimate Minecraft account.

## 🔒 Privacy at a glance

- Your data lives in a local `.fireclient` folder (or an existing `.justice-launcher` folder from an earlier install).
- Microsoft account tokens are stored locally, protected with the Windows Data Protection API.
- Crash logs are **never uploaded** by the launcher. Diagnostics are copied only when you choose to.
- The uninstaller leaves your worlds and game data untouched.
- Network requests go to the relevant providers (Microsoft/Xbox, Mojang, Modrinth, Fabric, Forge, NeoForge, Adoptium, PaperMC, GitHub, Discord) only when you use those features.

Full details: [Terms & Privacy](https://fireclient.net).
