FAQ

What is FireClient?#

A Minecraft Java launcher with an in-game client. The launcher handles versions, Java, mods, worlds and resource packs. The in-game client adds the menu and HUD.

Is FireClient free?#

Yes. The launcher and client are free to download and use. You need your own Minecraft Java Edition account to play online.

Is it FireClient or Fire Client?#

FireClient, written as one word. People also search for it as Fire Client. It is not the FireClient SMP mod on Modrinth.

Which systems does it run on?#

Windows 10 and 11 for sure. The GitHub README also lists macOS 12 or later and 64-bit Linux. See the download page.

Which Minecraft version has the in-game menu?#

Minecraft 1.21.1 on Fabric. The launcher can start other versions.

Is it open source?#

No. FireClient is proprietary. The GitHub repository holds the documentation, README and license information. See the license.

Is it safe to install?#

No installer can be promised safe. The beta is unsigned, so Windows may warn you. See Is FireClient safe?.

Will uninstalling delete my worlds?#

No. The installer and uninstaller leave worlds and resource packs on disk.

Will it boost my FPS?#

No benchmarks are published, so there is no speed claim. See Memory and performance.

Is FireClient affiliated with Mojang or Microsoft?#

No. It is independent and not endorsed by them.
