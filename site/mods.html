Install mods from Modrinth

You can manage mods without leaving the launcher.

Install a mod#

  1. Open the Mods page.
  2. Search for a mod or filter the list.
  3. Press Install.

Curated packs#

One-click packs are available for Performance, Visuals, Utility and PvP.

Your own jar files#

Drag and drop .jar files onto the Mods page. Make sure they match your Minecraft version and loader.

Manage installed mods#

The Library page lists installed mods with an on/off switch for each. You can also remove a mod there.

Library scan#

FireClient can match your installed mods to their Modrinth pages. To do this it sends file hashes to Modrinth. See Privacy.

Performance mods#

The Performance page lists optimization mods such as Entity Culling and FerriteCore. See Memory and performance.
