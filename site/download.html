Note: The FireClient GitHub README lists macOS and Linux builds. The website's early-access page still shows them as not available. If a link above fails, open the releases page and check which files that release includes.

Before you run it#

  • Download only from fireclient.net or the releases page above.
  • The installer is not code-signed yet, so Windows may warn you. See Is FireClient safe?.
  • You can check the SHA-256 hash of your file.

All published versions are listed in the release notes. The releases page has every tag.
