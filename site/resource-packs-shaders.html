Resource packs and shaders

The launcher has a page for Resource Packs and a page for Shaders. Each lists what you have installed for the current profile.

Your files stay put#

The pack library has no delete action. Updating or uninstalling FireClient leaves your packs on disk.

Folder shortcuts#

Use the buttons in the launcher to open the shaders folder or the instance folder.

Note: Shaders need a mod that supports them for your version. Install one from the Mods page first.
