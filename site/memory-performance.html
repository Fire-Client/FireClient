Memory and performance

Memory#

Choose a memory budget in the launcher. It is passed to Java as the max heap and kept inside a safe range. More is not always better. Too much can make garbage collection pauses worse.

Performance page#

The Performance page lists optimization mods such as Entity Culling and FerriteCore. Each one has an on/off switch, so you can test them one at a time.

Potato PC booster#

FireClient 1.1 added a Potato PC booster for low-end machines. See the release notes.

Honest numbers#

No FPS benchmarks have been published for FireClient. Results depend on your PC, so change one thing at a time and compare.

Tip: Press F3 in game to see FPS and memory use before and after a change.
