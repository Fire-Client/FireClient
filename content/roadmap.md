Planned items are not built. Dates can move.

## Live now

Early access, with the launcher and the in-game client for Minecraft 1.21.1:

- Draggable HUD with 11 elements and 3 accent themes
- Modrinth mod manager and curated packs
- Worlds library, memory control and local skins
- Fabric, Forge and NeoForge in the launcher
- Host Server for local Paper servers

## Planned

- Crosshair editor and cosmetics
- More in-game HUD modules and layout options
- One-click backup and restore for worlds
- Import profiles from other launchers
- More Minecraft versions for the in-game client

## Full version

Planned for November 2026. The exact date will be announced on the website, in the Discord and in the RSS feed.
