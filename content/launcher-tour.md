The launcher has one sidebar. Each page does one job.

| Page | What it does |
|---|---|
| Home | Shows your account, version, loader and memory. Has quick links and the Discord member count. |
| Versions | Installs Minecraft versions and their Java runtime. |
| Mods | Searches Modrinth, installs packs and manages installed mods. |
| Resource Packs | Lists and manages your resource packs. |
| Shaders | Lists and manages shader packs. |
| Worlds | Lists local worlds with icon, last-saved date and size. |
| Servers | Saves servers you play on. You can star up to 10 and they show on Home. |
| Host Server | Runs and manages a local Paper server. |
| Screenshots | Browse the screenshots you took in game. |
| Accounts | Switch between offline and online accounts. |
| Skins | Keeps your offline skin. |
| Performance and Usage | Memory settings and performance mods, plus usage information. |

## Console

A live console shows install and launch progress, game output and errors as they happen.

## Folder shortcuts

Buttons open your instance, mods, screenshots, saves and shaders folders in your file manager.

## Discord Rich Presence

Optional. When on, Discord shows your version and server. It only talks to your local Discord app.
