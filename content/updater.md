## Updater

The launcher has a standalone Updater with live SHA-256 verification and release notes. A Multi-OS Install Hub in the app lists builds for each system.

## Manual update

Download the new installer from the [download page](download.md) and run it. Your game data stays where it is.

## Uninstall

Remove FireClient with your system's uninstaller. The installer and uninstaller leave your game-data folder in place, including worlds and resource packs.

> **Warning:** Delete the `.fireclient` folder by hand only if you are sure you do not need your worlds. Back them up first.
