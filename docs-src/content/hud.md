Press <kbd>Right Shift</kbd> in a Minecraft 1.21.1 Fabric world, or use the **FireClient Menu** button on the title screen.

## The menu

The menu has Mods, Settings, Keybinds and Mod List tabs. Settings are split into HUD, Features, Theme and About. Profiles named Default, PvP, Builder and Performance let you switch layouts fast, and each module has an Enabled switch.

## HUD elements

There are 11:

| Element | Shows |
|---|---|
| Watermark | The FireClient mark |
| FPS | Frames per second |
| Coordinates | Your position |
| Ping | Latency to the server |
| Direction | Which way you face |
| Memory | Memory in use |
| Clock | The time |
| Keystrokes | WASD and mouse keys |
| Armor | Your armor |
| Effects | Active potion effects |
| CPS | Clicks per second |

## Arrange the HUD

1. Open the menu.
2. Switch on the elements you want.
3. Open the HUD editor and drag each one into place.
4. Pick one of the three accent themes.

The sprint toggle is in the same menu. Positions, visibility and the sprint toggle save to [`config/fireclient/client.json`](files-folders.md).

> **Note:** A crosshair editor and cosmetics are planned. They are not built yet.
