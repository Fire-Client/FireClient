# System Requirements

FireClient is heavily optimized for resource efficiency while utilizing modern multi-threaded rendering pipelines for modern Minecraft versions (1.20+ / 1.21+).

---

## 💻 Hardware Specifications

| Component | Minimum Requirements | Recommended Specifications |
| :--- | :--- | :--- |
| **Operating System** | Windows 10 (64-bit), Ubuntu 20.04+, macOS 11+ | Windows 11 / Modern Linux 64-bit |
| **Java Runtime** | Java 21 (OpenJDK / Eclipse Temurin) | Java 21 64-bit (bundled with launcher) |
| **Processor (CPU)** | Intel Core i3-3210 3.2 GHz / AMD A8-7600 APU | Intel Core i5-8400 / AMD Ryzen 5 3600 or higher |
| **Memory (RAM)** | 4 GB system RAM (2 GB allocated to game) | 8 GB+ system RAM (4 GB allocated to game) |
| **Graphics (GPU)** | Integrated Intel HD 4000 / AMD Radeon R5 (OpenGL 4.4+) | NVIDIA GeForce GTX 1060 / AMD Radeon RX 580 or higher |
| **Storage** | 1.5 GB free storage (HDD or SSD) | 4 GB+ high-speed NVMe/SATA SSD |

---

## ☕ Java Compatibility Matrix

Minecraft versions 1.20.5 and above require **Java 21**. 

* If you are using the **FireClient Launcher**, the appropriate 64-bit Java 21 runtime is downloaded and isolated automatically.
* If you are using the **FireClient Fabric Jar** manually in a custom launcher (Prism, MultiMC, or Vanilla), ensure the instance is explicitly configured to use a 64-bit Java 21 JDK or JRE.
